[슬라이드 16]  예제 1-2. GitHub 저장소 만들고 Claude Code로 연결
— 프롬프트 G-1 — 웹에서 빈 저장소 edu-apply를 만든 뒤, VS Code에서 1_시작 폴더를 열고 (내 GitHub 아이디)를 바꿔서
------------------------------------------------------------------
이 폴더를 GitHub 저장소에 연결하려고 해. 아래 순서로 해줘.
1. git --version 으로 git이 있는지 확인해줘. 없으면 설치 방법만 알려 주고 멈춰.
2. 이 폴더를 git 저장소로 만들고, .gitignore에 .env가 들어 있는지 확인해줘.
3. 커밋 사용자 정보가 없으면 이 저장소에만 설정해줘.
   이름 = (내 GitHub 아이디) · 이메일 = (내 GitHub 아이디)@users.noreply.github.com
4. 파일 전부를 첫 커밋("3회차 완성본")으로 만들고,
   https://github.com/(내 GitHub 아이디)/edu-apply.git 에 main 가지로 push해줘.
push할 때 브라우저 로그인 창이 뜨면 내가 승인할게. 끝나면 확인할 GitHub 주소를 알려줘.
------------------------------------------------------------------
※ Claude Code가 명령 실행을 물으면 허용합니다. 처음 push 때 브라우저 창에서 GitHub 로그인 · Authorize.
