--- 안 될 때 -----------------------------------------------------------
화면 메시지 / 오류                                 → 이렇게
"config.js에 Supabase 주소와 공개용 키를 넣어 주세요" → 예제 2-2 다시 · config.js 저장했는지
"비밀 키(Secret · service_role)가 들어 있습니다!"   → 지우고 Publishable 키로
                                                     이미 GitHub에 올렸다면 Supabase에서 키 재발급
relation "public.edu_apps" does not exist          → 예제 1-6 SQL을 안 돌림 (부록 문의 접수 현황판은 inq_list)
"가입은 됐지만 바로 로그인되지 않았습니다"           → Supabase → Authentication → Email → Confirm email 끄기
"로그인해야 할 수 있습니다"                           → 로그인 전에는 읽기만 됩니다 = 정상 차단
"내 신청이면서 '신청' 상태인 것만 지울 수 있습니다"  → 남의 신청 · 이수 · 취소 · 처음 가상 건 = 정상 차단
로그인했는데 신청이 "권한" 오류                       → supabase_login.sql 을 안 돌렸거나, setup.sql을 다시 돌린 뒤 login.sql을 안 돌림
'git'은(는) 내부 또는 외부 명령 … 이 아닙니다      → Git 설치 뒤 VS Code를 완전히 닫았다 다시 열기
push가 rejected (fetch first)                         → 저장소를 README 체크해서 만듦 → Claude Code에
                                                        "원격 내용을 먼저 받아서 합친 뒤 다시 push해줘"
Author identity unknown / 이메일 설정 요청            → G-1의 3번(이 저장소에만 이름 · 이메일 설정)을 다시
push 때 로그인 창이 안 뜨거나 실패                     → 웹 업로드로 우회 (예제 1-2 ⏱) · 지원센터에 채팅
push했는데 대표 주소가 그대로                          → Vercel Deployments 확인 · GitHub 저장소에 커밋이 올라갔는지
permission denied for table …                      → 화면 밖(F12)에서 못 고치는 칸을 고치려 함 = 정상 차단
                                                     화면에서 처음부터 이 메시지면 SQL 전체를 다시 Run
"정원 마감 : …" / "중복 신청 : …"                    → 정상입니다. DB가 규칙대로 막은 것
남이 내 주소를 열면 Vercel 로그인 화면이 뜸         → 긴 주소를 붙임. 짧은 대표 주소(저장소이름.vercel.app)로
배포 주소가 옛 화면 그대로                            → GitHub에 파일을 안 올림 · Vercel Deployments 확인
로컬은 되는데 배포본만 안 됨                          → config.js 를 GitHub에 안 올림
화면은 뜨는데 목록이 비어 있음                       → F12 → Console 의 맨 위 빨간 줄 → [오류 수정 요청]
                                                     ※ 코드가 깨져도 Vercel 배포는 Ready(성공)로 나옵니다.
                                                       이 앱은 빌드 단계가 없어서 오류는 브라우저에서만 보입니다

[프롬프트 G-1] 예제 1-2 · 슬라이드 16 — 저장소 연결 · 첫 push
----------------------------------------------------------------------
이 폴더를 GitHub 저장소에 연결하려고 해. 아래 순서로 해줘.
1. git --version 으로 git이 있는지 확인해줘. 없으면 설치 방법만 알려 주고 멈춰.
2. 이 폴더를 git 저장소로 만들고, .gitignore에 .env가 들어 있는지 확인해줘.
3. 커밋 사용자 정보가 없으면 이 저장소에만 설정해줘.
   이름 = (내 GitHub 아이디) · 이메일 = (내 GitHub 아이디)@users.noreply.github.com
4. 파일 전부를 첫 커밋("3회차 완성본")으로 만들고,
   https://github.com/(내 GitHub 아이디)/edu-apply.git 에 main 가지로 push해줘.
push할 때 브라우저 로그인 창이 뜨면 내가 승인할게. 끝나면 확인할 GitHub 주소를 알려줘.
----------------------------------------------------------------------

[프롬프트 G-2] 예제 2-3 · 2-6 · 슬라이드 28 · 33 — 커밋 · push
----------------------------------------------------------------------
바뀐 파일을 보여 주고, 무엇을 바꿨는지 한 줄 커밋 메시지를 써서 커밋한 뒤 push해줘.
새 가지(branch)는 만들지 말고 main 가지에 바로 커밋 · push해줘.
